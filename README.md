# ContentFlow

Public-source, extensible Content Management System (CMS) built with .NET 10 and Blazor.

## Features (planned)
- Traditional CMS with Static SSR public website
- Headless CMS API with OpenAPI/Scalar
- Modular architecture with Clean Architecture
- Relational-first PostgreSQL persistence
- Admin UI (Interactive Server), Shop area (Interactive Server)
- Extensible via explicit contracts
